# AI Prompts Used During Development

AI tools were used for guidance, debugging, and design suggestions during development.

## Prompts Used

### 1. Understanding Requirements

"Help me understand the requirements for this project and plan the implementation."

### 2. UI and Responsive Design

"Suggest improvements to make the website responsive and user-friendly."

### 3. Debugging

"Help me identify and fix issues in my HTML, CSS, and JavaScript."

### 4. Documentation

"Help me organize the project documentation and add screenshots to the README."

AI assistance was used as a support tool during development and debugging.
